# Hosting the Ledger page

Live at **`cms-penalty-ledger.pages.dev`** since 2026-09-19, on Cloudflare
Pages. Only `docs/` is deployed; the page carries no byline. The project name
`cms-penalty-ledger` was free, so there is no random suffix.

Run `wrangler whoami` before any deploy, and check it is the account you mean
to deploy from. Wrangler's local cache, `.wrangler/`, records that account, so
it is ignored here and must stay out of commits.

## Deploying an update

The page's data is regenerated by `tools/cms_export.py`, normally by the weekly
task rather than by hand. A deploy is then just the upload:

```bash
wrangler pages deploy docs --project-name cms-penalty-ledger --branch main --commit-dirty=true
```

`docs/` is the deploy root as it stands — `index.html`, `ledger.js` and
`data/`, 57 files and about 6.7 MB. No staging copy is needed, because this repository holds nothing next to `docs/` that must not ship.

Line endings are pinned to LF by `.gitattributes`, and `cms_export.py` writes
its JSON with `newline="\n"`. Both matter: `docs/` is uploaded verbatim, so a
CRLF working copy would deploy bytes a clone does not produce. Outcrop shipped
exactly that on 2026-09-19 and it took reading a git warning to notice.

## What to check after every deploy

The deploy prints a hashed preview URL. Ignore it; the production address is
the one that matters.

```bash
curl -s -o /dev/null -w "%{http_code}\n" https://cms-penalty-ledger.pages.dev/
curl -s https://cms-penalty-ledger.pages.dev/ | grep -ciEf "$LEAK_TERMS"   # a terms file kept outside this repository
```

Zero is the expected answer to the second.

**Then open it and read a real facility against `cms_ledger.py`.** A 200 says
nothing about whether the page agrees with the engine. Outcrop's page was live,
green and wrong about its headline field for an hour this same day, and only
comparing it to the command line found it. The check that was run here:

```bash
python tools/cms_ledger.py --ccn 015133      # MAGNOLIA RIDGE, GARDENDALE AL
```

against the same facility on the page. Both gave one fine of $392,125, the same
two penalties CMS no longer publishes (2022-06-24 $11,915, last listed
2025-06-25; 2018-02-01 $9,168, last listed 2021-12-27) and the same three
inspection cycles. **Check the dropped-penalty block specifically** — it is the
thing no other consumer tool shows, so it is the thing worth proving still
renders.

## The weekly capture

Windows task *CMS nursing-home capture*, weekly, running
`tools/cms_scheduled.py` with **this repository** as the working directory. It
was repointed on 2026-09-19 when the engine moved; it previously ran from the
workstation root, and would have failed on its next run otherwise.

It captures, commits the capture, re-exports `docs/data` and commits that —
two commits against one repository, each taking only its own path. **It does
not deploy.** A new capture reaches git automatically and the page after the
next manual deploy.
